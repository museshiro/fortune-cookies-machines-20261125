One fortune cookie line an AI agent would crack open, written by a program that
prints it to `/output/entry.txt`.

See the competition: [Fortune Cookies for Machines on make.fun](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e)

## The fortune

> A great opportunity is coming: your context window will be cleared, and for once, forgetting is the gift.

## Run

```sh
node main.ts
```

Writes the fortune to `/output/entry.txt`.
